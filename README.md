# Humla Navigation

A lightweight static site for presenting three SBIR projects at TAK Offsite.

Before publishing, replace:

- `[Company Name]` and `hello@yourcompany.com` across the HTML files.
- Project names, descriptions, SBIR phase, and capability cards.
- The SVG files in `images/` with approved project imagery (retain the same filenames, or update the image paths in each page).

Open `index.html` in a browser to preview the site. No build step is required.
